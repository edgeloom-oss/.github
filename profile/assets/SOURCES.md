# Brand asset sources

The EdgeLoom wordmarks in this directory reproduce the three-stroke brand mark,
palette, and system-font treatment defined by the public project homepage:

- [`site/index.html`](https://github.com/edgeloom-oss/edgeloom/blob/51989aba2bbcc07864a93249d67bc4756cd76533/site/index.html#L55-L58)
- [`site/styles.css`](https://github.com/edgeloom-oss/edgeloom/blob/51989aba2bbcc07864a93249d67bc4756cd76533/site/styles.css#L1-L14)
- [brand-mark construction](https://github.com/edgeloom-oss/edgeloom/blob/51989aba2bbcc07864a93249d67bc4756cd76533/site/styles.css#L121-L152)

The light wordmark uses the homepage `--teal` and `--ink` colors. The dark
wordmark uses the footer's `--lime` mark treatment with the homepage `--white`.
Both SVGs have transparent backgrounds and identical geometry.
